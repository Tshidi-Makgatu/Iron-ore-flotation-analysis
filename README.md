# Iron Ore Flotation Plant Data Analysis

## Project Overview

This project focuses on cleaning, exploring, and analysing operational data from an iron ore flotation plant using SQL.

The objective is to investigate operational variables and product quality indicators to better understand relationships within the flotation process and identify trends that may support process optimisation.

## Dataset

The dataset contains approximately 737,453 observations of flotation plant operational data.

### Variables Included

- Iron feed grade
- Silica feed grade
- Starch flow
- Amina flow
- Ore pulp flow
- Ore pulp pH
- Ore pulp density
- Air flow across flotation columns
- Flotation column levels
- Iron concentrate grade
- Silica concentrate grade
- Date and time

## Tools

- MySQL
- SQL
- GitHub

## Project Objectives

1. Inspect and understand the dataset.
2. Identify missing values and duplicate records.
3. Clean and prepare the data.
4. Conduct exploratory data analysis using SQL.
5. Investigate relationships between operating variables and concentrate quality.
6. Communicate findings through data-driven insights.

## Analysis Questions

- What is the average iron concentrate grade?
- What is the average silica concentrate grade?
- How does feed quality vary over time?
- What relationships exist between operating variables and product quality?
- How does pulp pH vary throughout the dataset?
- How do air flow and column levels vary between flotation columns?
- What trends can be identified in reagent consumption?
